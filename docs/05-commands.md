# Commands

| Command | What it does |
|---|---|
| `make install` | install everything |
| `make dev` | start the server |
| `make test` | run the tests |
| `make check` | run all checks (code style, types, tests) |
| `make docker` | run in Docker |
| `make diagnose` | test which Instagram requests work from your internet/proxy |
| `make diagnose-login` | check Instagram's login pages (doesn't log in, no password sent) |
| `make memory-sync` | save Claude's project memory into the repo |
