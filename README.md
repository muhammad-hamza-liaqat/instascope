# InstaScope

Give it an Instagram username and it returns that profile's details: bio, profile picture,
followers, posts, reels and follower history.

**Author:** Hamza ([@muhammad-hamza-liaqat](https://github.com/muhammad-hamza-liaqat))

## Quick start

```bash
git clone https://github.com/muhammad-hamza-liaqat/instascope.git
cd instascope
make install
cp .env.example .env
make dev
```

Then open **http://127.0.0.1:8000**.
